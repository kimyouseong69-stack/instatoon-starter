# 인스타툰 스타터

대본 한 장으로 **인스타툰 카드 → 릴스 영상 → 캡션 → 바로 올릴 꾸러미**까지.
코딩을 몰라도 돼요. Claude Code에게 말로 시키면 되도록 만들어 둔 작업 폴더예요.

![예시](samples/예시편/EP00_샘플/card1.png)

## 시작하기 (맥)
1. [처음 설치](docs/01_처음_설치.md) — Homebrew · Claude Code · 이 저장소 받기 · harness 플러그인
2. 이 폴더에서 `claude` 실행 → **「이 폴더 세팅해 줘」**
3. **「인스타툰 하네스 구성해 줘」** → [하네스 만들고 첫 편](docs/03_하네스_만들고_첫_편.md)
4. **「올릴 꾸러미 만들어 줘」** → 휴대폰으로 에어드롭 → 인스타 앱에서 올리기
5. (보너스) 크롬 컴퓨터 유즈로 클로드가 instagram.com 에 올리기 · (선택) [API 바로 게시 연결](docs/02_인스타_API_연결.md) — [업로드 세 가지 방법](samples/노하우/06_업로드.md)

## 완성품이 아니라 재료예요
스킬·에이전트는 들어 있지 않아요. **harness 로 나만의 하네스를 직접 만들고**, 그때 쓰라고 검증된 재료를 넣어 뒀어요.

| 재료 (`samples/`) | |
|---|---|
| 엔진 | 컷 조립(말풍선·나레이션·효과음·표지 → 1080×1350 카드) · 릴스 변환(줌·전환·효과음) · 그림(무료 코드 그림 / 유료 AI, 비용 먼저 보고) · 효과음 합성 · 올릴 꾸러미(카드 JPG·릴스·캡션) · 인스타 API 게시(선택) |
| 노하우 | 이야기 구조 · 조립 규칙 · AI 그림 요령 · 캡션 · 릴스 · 업로드 · **저작권·라이선스 체크(글꼴 상업 사용·AI 그림·효과음·남의 이야기)** |
| 예시편 | 완성 예시 «월요일 아침»(대본→카드 7장→릴스→캡션) + 새 편 템플릿 |
| 참고 스킬 | 완성된 스킬·에이전트 견본 2+1개 |
| 에셋 | 글꼴 3종(OFL) · 직접 합성한 효과음 12개 · 샘플 캐릭터 「말랑이」 |

## 들어 있는 클로드 세팅 (`.claude/settings.json`)
파일 편집 자동 허용 · 작업 끝나면 「띵」 · 상태줄(대화 사용량) · harness 플러그인 등록 · `.env` 읽기·`git push` 차단

## 안전하게 쓰기
- 키·토큰은 **`.env` 에만**, 넣을 땐 `bash tools/set_key.sh 이름`(입력이 화면에 안 보여요). `.env` 는 깃허브에 안 올라가고 클로드도 못 열어요.
- 내 저장소를 깃허브에 올리기 전에는 `bash tools/check_leaks.sh`.
- 내가 만든 편(`episodes/`)은 기본으로 깃허브에 안 올라가요.
