# EP.00 «월요일 아침» 대본 (샘플)

> 지어낸 이야기입니다. 내 편은 이 형식으로 대본부터 쓰고, 승인한 뒤에 그림으로 넘어갑니다.

| 컷 | 장면 | 글자 |
|---|---|---|
| 표지 | 이불 속, 옆에서 울리는 알람 | 훅 「알람 다섯 번 끄고」 / 제목 「월요일 아침」 / 부제 「5분만 더…」 |
| 1 | 깜깜한 새벽, 머리맡 알람이 크게 울림 | 나레이션 「새벽 여섯 시, 알람이 울렸어요.」 / 효과음 「띵띵띵」 |
| 2 | 손만 뻗어 알람을 끔 | 생각 「딱 5분만 더…」 / 효과음 「탁」 |
| 3 | 환한 아침, 시계를 보고 화들짝 | 나레이션 「눈을 떠 보니 여덟 시 반.」 / 효과음 「헉!!」 |
| 4 | 땀 흘리며 뛰어나감 | 대사 「늦었다 늦었다!」 / 효과음 「후다닥」 |
| 5 | 달력에 빨간 동그라미, 멍한 얼굴 | 나레이션 「그런데 달력을 보니…」 / 효과음 「띠용」 |
| 6 | 다시 이불 속, 행복한 얼굴 | 나레이션 「오늘, 쉬는 날이었어요.」 / 생각 「다시 잘래…」 / 질문 「여러분도 이런 날 있으셨나요?」 |

구조: 표지 → 상황(1~2) → 「그런데」 꺾임(3~5) → 남은 마음 + 댓글 유도(6)
