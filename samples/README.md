# samples — 하네스 재료

여기 있는 건 「완성품」이 아니라 **재료**예요. 클로드에게 이렇게 말해 보세요.
> 인스타툰 하네스 구성해 줘. samples 폴더 재료를 써서.

| 폴더 | 내용 |
|---|---|
| `엔진/` | 실제로 돌아가는 코드(컷 조립·렌더·릴스·그림·효과음·올릴 꾸러미·API 업로드) |
| `노하우/` | 이야기 구조 · 조립 규칙 · AI 그림 요령 · 캡션 · 릴스 · 업로드 · 저작권·라이선스 체크 |
| `예시편/` | 완성 예시 «월요일 아침»(EP00) + 새 편 템플릿 |
| `참고_스킬/` | 완성된 스킬·에이전트 견본 |
| `에셋/` | 글꼴 · 효과음 · 샘플 캐릭터 · 라이선스 기록표 |
