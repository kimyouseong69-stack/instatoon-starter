# AI 그림 요령

## 두 가지 방법 — 프롬프트 파일은 하나(`ai_prompts.md`)
| | 방법 | 도구 | 비용 |
|---|---|---|---|
| **기본** | **ChatGPT 복붙** — 클로드가 프롬프트를 쓰고, 사람이 ChatGPT 웹에 붙여 넣어 뽑는다 | `scripts/chatgpt_prompts.py`(복붙용 프롬프트 · `--copy s1`) → `scripts/import_images.py`(다운로드 폴더 → 컷 이름) | ChatGPT 구독 안에서(추가 비용 없음, 하루 생성 한도는 있음) |
| 유료 자동 | **OpenAI API** — 클로드가 직접 뽑는다 | `scripts/gen_scenes.py` (`.env` 의 OPENAI_API_KEY) | 장당 과금 — 아래 비용 규칙 |

형식 견본: `samples/예시편/_템플릿/ai_prompts.md` (캐릭터 시트 → 공통 헤더 → 표지 → 컷)
아래 요령(캐릭터 유지·감정·카메라·글자 금지)은 **두 방법 모두 같다** — 프롬프트에 박아 두면 ChatGPT 에서도 그대로 통한다.

## ChatGPT 복붙 순서
1. `chatgpt_prompts.py <편>` → `ChatGPT_복붙.md`(컷마다 완성 프롬프트 + 저장 이름)
2. 컷마다: 클로드가 `--copy sN` 으로 클립보드에 넣음 → ChatGPT 에 **캐릭터 그림 첨부** + 붙여 넣기 → 다운로드
   - 같은 채팅에서 이어 그리면 그림체가 덜 흔들린다. 그래도 캐릭터가 바뀌면 **매번 첨부**가 답.
   - 마음에 안 들면 같은 채팅에서 「눈을 더 크게」처럼 고쳐 달라고 한다(새로 뽑는 것보다 빠름).
3. 다 받으면 `import_images.py <편>` → **받은 순서 ↔ 컷 이름 짝을 먼저 보여 주고** 확인 후 `--apply`. 한 컷만 다시 받았으면 `--names s3 --apply`.
   - 그림은 4:5 로 맞춰진다(2:3 으로 받으면 위를 잘라냄 → 프롬프트가 위쪽을 비워 두게 시켜 둠).
   - 순서가 꼬이면(중간에 다른 그림을 받음) `--names` 로 순서를 직접 적는다.

## ChatGPT 복붙을 클로드에게 맡기기 (크롬 컴퓨터 유즈, 2026-10-20 1컷 시험 성공)
사람이 복붙하는 대신 클로드가 크롬의 ChatGPT 를 직접 조작한다. 추가 비용 없음(구독 한도 안), 대신 컷당 1~2분.
준비: 크롬 Claude 확장 + `claude --chrome`(**저장소 폴더에서** — 클로드는 켜진 폴더 안 파일만 첨부할 수 있음) + 크롬에서 chatgpt.com **사용자가 직접 로그인**.
클로드가 하는 순서 (컷마다):
1. `chatgpt_prompts.py <편> --copy sN` → 프롬프트가 클립보드에
2. chatgpt.com 새 채팅 → 첨부용 파일 입력(「사진 또는 동영상 첨부」)에 캐릭터 그림을 `file_upload`
3. 입력창 클릭 → `cmd+v` 붙여 넣기 → 보내기
4. 1~2분 기다리며 화면 확인(진행률 %가 보임)
5. 저장: 다운로드 버튼은 마우스를 올려야 나타나 잘 안 잡힘 → 페이지에서 가장 큰 생성 그림(가로 1000px 이상)을 받아 **`sN.png` 이름으로 저장**(다운로드 폴더)
6. 다 받으면 `import_images.py <편> --apply`(이름이 sN 이라 짝이 안 꼬임)
- 그림을 보고 마음에 안 들면 같은 채팅에 「눈을 더 크게」처럼 고쳐 달라고 한 뒤 다시 저장.
- ChatGPT 화면 이름은 바뀔 수 있다 → 못 찾으면 화면을 찍어 보고 찾기, 그래도 안 되면 사람에게 「이 컷만 직접」.

## 비용 규칙 — API 자동일 때 (순서가 규칙)
1. 뽑기 전에 `--plan` 으로 「몇 장 × 얼마」를 **먼저 보여 주고** 확인받는다. 다 뽑고 나서 통보하지 않는다.
2. 시험은 **low**. 이 그림체(굵은 선·평면 색)는 high 와 품질 차이가 거의 없다. 구도가 마음에 안 들면 high 로 올리지 말고 low 로 여러 번 다시 뽑는다(10번 뽑아도 high 한 장보다 싸다).
3. 규칙을 먼저 공통 헤더에 박고 시작한다. 뽑아 보고 나서 규칙을 알아내면 재작업이 두 배가 된다.
4. 호출 기록은 `_작화비용.log` → `cost.py` 로 합계.

## 같은 캐릭터 유지
- **캐릭터 시트를 먼저 한 장** 만들고, 매 컷 참고 그림으로 붙인다(gen.json 의 `ref`).
- 조연 캐릭터는 몸 색까지 묶어서 지정한다(껍질·머리색만 말하면 주인공과 같은 색으로 나와 구분이 안 됨).
- 「이 그림에 주인공은 정확히 하나」를 적는다(사람 많은 컷에서 주인공이 둘 나오는 사고).

## 감정은 기본값으로 약하게 나온다
- 「피곤」「신남」「슬픔」을 그냥 시키면 멀쩡한 얼굴이 나온다. **눈 모양·입·눈썹·자세·소품**까지 묶어서 지시.
  - 피곤 = 다크서클·반쯤 감긴 눈·굽은 등·처진 어깨
  - 신남 = 크게 뜬 눈 또는 ^^ 눈·크게 벌린 입·발이 땅에서 뜸
  - 슬픔 = 고개 숙임·떨군 눈·눈물 한 줄·꾹 다문 입 + `NOT cute, NOT pouty`
- 집에 도착하는 장면은 모델이 자동으로 웃게 만든다 → 원하지 않으면 `ABSOLUTELY NO SMILE`.
- 표정 과장은 정점 1~3컷에만. 전부 과장하면 이상해진다.

## 카메라
- 같은 구도 두 번 연속 금지. **컷마다 카메라를 문장으로** — 「바닥에서 올려다보며」「어깨 너머로」「천장에서 내려다본 방 전체」. 「MEDIUM shot」 같은 말만으로는 거리가 안 바뀐다.
- 두 사람 나란히 눈높이 구도는 한 편에 한 번.
- 갈등 장면은 상대를 신체 일부·소품으로(올려다본 거대한 손가락, 클립보드 클로즈업).

## 동작은 「끝난 순간」을 시킨다
- 내려가는 중 → 「다 내려와 마지막 계단을 밟는 순간」(모델은 방향을 자주 뒤집는다)
- 문을 여는 중 → 「문에 손도 안 댄 채 첫발을 떼는 순간」

## 얼굴 없는 사람
- 「머리를 잘라라」라고 쓰면 목 잘린 몸·검은 머리가 나온다(섬뜩). → **「화면 위 끝이 가슴 높이에서 자른다」**, 멀리 있는 사람은 뒷모습.

## 장소 이어 그리기(앵커)
- gen.json `anchor` 로 앞 컷을 참고 그림으로 붙이면 같은 방이 나온다. 단 **카메라 위치까지 복사**된다 → 꼭 필요한 한두 컷만.
- 전후 대비(가득 → 텅 빔)에는 오히려 정답.

## 글자는 그림에 그리게 하지 않는다
- 공통 헤더에 `NO text, NO letters, NO numbers, NO speech bubbles`. 글자는 조립 때 얹는다.
- 위쪽 캡션 여백을 시키면 흰 띠가 생긴다 → 글이 없는 컷은 그 띠를 잘라낸다.
