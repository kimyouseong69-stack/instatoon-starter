# 저작권·라이선스 체크 (올리기 전에)

> 법률 자문이 아니라 **「멈춰서 확인할 지점」 목록**입니다. 애매하면 쓰지 않거나 전문가에게 물어보세요.
> 클로드에게 물을 때도 「기억으로 답하지 말고 **원문 페이지를 열어서** 확인해 줘」라고 하세요. 라이선스는 자주 바뀝니다.

## 한눈에 — 신호등
| | 뜻 | 예 |
|---|---|---|
| 🟢 | 근거(라이선스 원문)를 확인했고 상업 사용 OK | OFL 글꼴, 직접 만든 그림·소리 |
| 🟡 | 조건이 있거나 원문을 아직 못 봄 → **확인 전엔 쓰지 않기** | 「무료 폰트」라고만 적힌 글꼴, 출처 모르는 이미지 |
| 🔴 | 쓰면 안 됨 | 남의 캐릭터, 번역서 문장 통째로, 재배포 금지 소리를 깃허브에 올리기 |

## 1. 글꼴
**「무료」와 「상업 무료」는 다릅니다.** 개인만 무료인 글꼴이 많아요.

확인할 것 (배포처 원문 페이지에서):
- [ ] **상업적 사용** 가능? (인스타 계정으로 홍보·판매를 하면 상업적 사용으로 봅니다)
- [ ] 사용 범위 표에 **영상·SNS·인쇄·웹·임베딩(PDF·앱 안에 넣기)**이 다 허용?
- [ ] **글꼴 파일을 함께 배포**해도 되나? (깃허브에 .ttf 를 올리는 것 = 배포)
- [ ] 이름을 바꿔야 하는 조건(Reserved Font Name)이나 출처 표기 조건이 있나?

자주 보는 라이선스:
- **SIL OFL 1.1** — 상업 사용·영상·인쇄·임베딩 OK, 함께 배포 OK(라이선스 파일 동봉). **글꼴 파일만 따로 파는 건 금지.** 고쳐서 배포하면 원래 이름(Reserved Font Name)을 쓰면 안 됨.
- 「눈누」 같은 모음 사이트의 표는 **요약**입니다. 최종 확인은 **글꼴을 만든 회사·기관의 원문 페이지**에서.
- 기업 전용 글꼴(○○체)은 「그 회사 홍보물에만」 같은 조건이 붙기도 해요.

이 저장소 글꼴 3종은 전부 OFL 1.1 이고, 라이선스 원문을 `samples/에셋/fonts/` 에 함께 두었습니다 → `samples/에셋/라이선스_기록표.md`

## 2. 이야기 (대본)
- **아주 오래된 원전**(전래동화·탈무드·이솝·고전)의 줄거리는 누구나 쓸 수 있어요.
- 그런데 **요즘 나온 번역서·그림책·해설서의 문장과 그림은 그 책의 저작권**이에요. → **줄거리만 가져오고 문장은 새로 쓰기.** 인물 묘사·장면 구성도 새로.
- 남의 웹툰·소설·드라마 줄거리를 그대로 옮기는 건 🔴.
- 클로드에게: 「줄거리만 참고해서 우리 말로 새로 써 줘. 특정 번역서 문장을 쓰지 마」

## 3. 그림
**AI 그림 (OpenAI)**
- OpenAI 이용약관은 결과물(Output)의 권리를 **법이 허용하는 범위에서** 사용자에게 넘겨준다고 적고 있어요. 다만 **같은·비슷한 결과물이 다른 사람에게도 나올 수 있다**고도 적혀 있어요.
- 한국 정부 안내서(2025.6, 문화체육관광부·한국저작권위원회 「생성형 AI 활용 저작물의 저작권 등록 안내서」)는 **사람이 창작적으로 기여한 부분만** 저작권이 인정되고, 프롬프트만으로는 인정되기 어렵다는 입장이에요.
  → AI 그림을 써도 되지만, **「내 그림이니 아무도 못 쓴다」고 주장하기는 약할 수 있어요.** 대본·글자 배치·컷 구성처럼 내가 만든 부분이 내 것의 중심이에요.
- 프롬프트에 **실존 작가 이름·남의 캐릭터 이름**을 넣지 않아요(「○○ 작가 스타일로」 🔴).

**남의 것**
- 만화·게임·애니·브랜드 **캐릭터** 🔴 (패러디라도 위험)
- **실존 인물 얼굴**(연예인·정치인·지인) 🔴 — 초상권
- 인터넷에서 찾은 사진·그림을 배경으로 🔴 — 출처·라이선스 확인 전엔 쓰지 않기
- 거리 풍경: 옥외에 늘 놓인 건물·간판은 그릴 수 있어요(저작권법 제35조 제2항). 단 **캐릭터 저작물**(테마파크 마스코트 등)은 안 되고, 그 그림을 **굿즈 등으로 판매**할 땐 따로 확인.

**그림체·트레이싱** (근거·사례: `docs/00_시작하기_전에_주의사항.md`)
- 그림체·화풍 **자체**는 저작권 보호가 어렵다는 게 판사·법학 교수 의견 — 「느낌」은 써도 됨.
- 남의 그림 속 **캐릭터·컷 구도·포즈·배경**을 가져오면 표현을 베낀 것 🔴. 선을 안 따라 그려도 **구도·연출 유사성**으로 연재 중단된 사례가 있음(2025.7).
- 남의 그림·**사진** 위에 따라 그린 것(트레이싱)을 작품으로 올리기 🔴. 연습은 OK, 올리는 건 X.
- 남의 그림을 AI 에 넣고 변형 = 트레이싱과 같음 🔴. AI 에 넣는 그림은 **내 캐릭터**만.

**직접 만든 것** 🟢 — 코드로 그린 그림, 내가 그린 그림, 내가 찍은 사진(사람이 나오면 그 사람 동의).

## 4. 소리 (효과음·배경음악)
- 무료 효과음 사이트 소리는 **「영상에 넣는 건 OK, 파일 재배포는 금지」**인 경우가 대부분 → 영상엔 써도 **깃허브·드라이브 공유에 파일을 올리지 않기.** 「효과음만 나오는 영상」 금지 조건도 흔해요.
- 무료 BGM: **Content ID**(유튜브 저작권 자동 신고) 등록 곡인지, AI 생성 곡 표시가 있는지 확인.
- **인스타 앱 음악은 앱 안에서만.** 그 음악을 파일에 구워 넣어 올리면 🔴. 음악이 필요하면 인스타 앱에서 릴스 올릴 때 붙이기.
- 이 저장소의 효과음 12개는 코드로 합성한 것 🟢 (`samples/엔진/scripts/make_sfx.py`).

## 5. 개인정보·실제 사람
- 실제 겪은 이야기라도 **알아볼 수 있는 사람**(이름·얼굴·직장·특징)은 바꾸기.
- 다른 사람의 대화 캡처·사진은 동의 없이 쓰지 않기.

## 6. 하네스에 넣으면 좋은 체크 단계
업로드 직전에 자동으로 이 표를 채우게 하세요.
```
[라이선스 체크]
- 이야기: 원전 줄거리만 / 문장 새로 씀              🟢🟡🔴
- 그림: AI(OpenAI) · 직접 · 그 외(출처: )           🟢🟡🔴
- 글꼴: (이름 — 라이선스 — 원문 확인했나)            🟢🟡🔴
- 소리: 직접 합성 · 사이트(이름·약관 확인)            🟢🟡🔴
- 남의 캐릭터·실존 인물·개인정보 없음?               🟢🟡🔴
→ 🟡·🔴 가 하나라도 있으면 올리지 않고 사용자에게 묻기
```
새 글꼴·소리·그림을 추가할 때마다 `samples/에셋/라이선스_기록표.md` 에 한 줄씩 적어 두세요(출처·라이선스·확인한 날짜·원문 주소).
