# 릴스 (카드 → 9:16 영상)

도구: `samples/엔진/reel/toon_reel.py` — 새로 그리지 않고 화면 효과 + 효과음만 입힌다.

- **캐러셀(카드)을 확정한 뒤에** 만든다. 카드가 바뀌면 릴스를 다시 만들어야 한다.
- 컷 길이 = 그 컷 글자 수로 자동 계산(읽는 속도 초당 9자, 2.4~5.2초). 총 15~60초가 적당.
- 전환은 컷 성격대로 — 소리 나는 사건 컷 = 휙(swipe), 충격 = 번쩍+바로(cut), 조용한 컷 = 페이드, 가라앉는 컷 = 까맣게(dip), 따뜻한 마무리 = 하얗게(white). **전부 같은 전환이면 「다 똑같다」**가 된다.
- 효과음은 카드에 그린 효과음 글자로 고른다(`profiles/sfxmap.json`: 글자 → 소리 이름). 말풍선 대사엔 게임식 중얼중얼(babble).
- 9:16 은 4:5 카드보다 좌우가 좁다 → `fill_cards.py` 가 글자 상자를 안쪽으로 당겨 다시 렌더한다(휴대폰 기종마다 가장자리가 잘림: 좌우 ≥120px, 위 ≥270px, 아래 ≥470px 비우기).
- 음량은 -14 LUFS 근처. 검수: 1.5초 간격 프레임 시트 + `ebur128`.
- **음악**: 인스타 음악은 파일에 구워 넣으면 안 된다 → 앱에서 올릴 때 붙인다. API 로 올리면 음악을 못 붙인다. 무료 BGM 은 약관(재배포 금지·Content ID) 확인 후.
- 효과음 사이트에서 받은 소리는 대부분 **재배포 금지** → 깃허브에 올리지 않는다(이 저장소의 효과음 12개는 코드로 합성한 것).
