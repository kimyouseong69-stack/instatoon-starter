# 인스타 업로드 — 세 가지 방법

처음엔 **① 꾸러미 + 직접 올리기**를 기본으로 하세요. 연결할 것도, 토큰도 없어요.
②·③은 익숙해진 다음에 필요하면 붙이는 단계예요.

| | 방법 | 준비 | 이럴 때 |
|---|---|---|---|
| ① 기본 | 클로드가 **올릴 꾸러미**(카드 JPG·릴스·캡션)를 만들고, 업로드는 **내가 앱에서** | 없음 | 처음 · 음악을 붙이고 싶을 때 |
| ② 보너스 | 클로드가 **크롬을 직접 움직여** instagram.com 에 올림(컴퓨터 유즈) | 크롬 + Claude 확장 · 인스타 로그인은 내가 | 손이 바쁠 때 · 「이런 것도 된다」 체험 |
| ③ 선택 | **API 로 바로 게시**(`ig_publish.py`) | Meta 개발자 앱 + 토큰(docs/02) | 매일 올리고, 나중에 예약·자동화까지 갈 때 |

## ① 올릴 꾸러미 + 직접 올리기 (기본)
도구: `samples/엔진/upload/make_package.py`
```
.venv/bin/python samples/엔진/upload/make_package.py episodes/EP01_제목 --copy --open
```
- `<편>/올리기/` 에 `01.jpg …`(카드 순서대로, JPEG) · `reel.mp4` · `캡션.txt` · `올리는_순서.txt` 가 생겨요.
- `--copy` 캡션을 클립보드에 복사(같은 애플 계정이면 휴대폰에서 바로 붙여 넣기) · `--open` Finder 로 열기 → 에어드롭.
- 해시태그 5개 초과·비율 이상·10장 초과면 경고해 줘요.
- 휴대폰: + → 게시물 → 「여러 장 선택」 → **01 부터 순서대로** → 캡션 붙여 넣기 → 공유.
- 릴스는 앱으로 올리면 **인스타 음악을 붙일 수 있어요**(파일에 음악을 구워 넣는 건 🔴, 07 참고).

## ② 컴퓨터 유즈 — 클로드가 크롬으로 올리기 (보너스)
클로드가 내 크롬 화면을 보면서 클릭·파일 선택·글자 입력을 해요.
1. 크롬에 **Claude 확장 프로그램** 설치 → 구독 계정으로 로그인
2. 클로드를 `claude --chrome` 으로 켜기(또는 켜진 상태에서 `/chrome`)
3. 크롬에서 instagram.com 에 **내가 직접 로그인**(비밀번호를 클로드에게 주지 않기)
4. 클로드에게:
   > 올리기 폴더의 01~07.jpg 를 instagram.com 에 캐러셀로 올려 줘. 캡션은 캡션.txt. **마지막 「공유」 버튼은 누르지 말고 멈춰.**
5. 화면을 확인하고 **「공유」는 내가 누르기**
- 꾸러미(①)를 먼저 만들어 두면 클로드가 고를 파일이 분명해서 잘 돼요.
- 느려요(사람보다 몇 배). 「직접 하면 30초인 걸 클로드가 대신한다」는 체험용으로 생각하세요.
- 새로 만든 계정에서 짧은 시간에 여러 번 올리면 인스타가 막을 수 있어요 → 시험은 한두 번만.
- 인스타 화면이 바뀌면 버튼을 못 찾을 수 있어요 → 「지금 화면 보고 어디 눌러야 할지 알려 줘」로 바꾸기.

## ③ API 로 바로 게시 (선택)
도구: `samples/엔진/upload/ig_publish.py` · 연결 방법: `docs/02_인스타_API_연결.md`
- 필요한 것: 프로페셔널(크리에이터/비즈니스) **공개** 계정 + 페이스북 개인 계정(개발자 등록용). 페이스북 페이지·앱 검수·사업자 서류는 필요 없음(내 계정에만 쓰는 앱).
- 토큰은 대시보드 Generate token → **60일**. 권한: `instagram_business_basic` + `instagram_business_content_publish`.
- 인스타는 **공개 인터넷 주소(URL)의 파일만** 가져간다(내 컴퓨터 파일 직접 X) → 업로드 도구가 임시 주소(cloudflared)나 R2 를 만든다.
- 주소에 한글이 들어가면 실패 → 영문 파일명으로 바꿔서 보낸다(도구가 자동 처리).
- 이미지는 **JPEG 만**, 8MB 이하, 비율 4:5 ~ 1.91:1. 캐러셀 **2~10장**.
- 릴스: mp4(H.264/AAC), 3초 이상. 인스타 처리(`FINISHED`)를 기다린 뒤 게시 — 1~5분. API 로는 인스타 음악을 못 붙인다.
- 순서: `whoami`(어느 계정인지) → `--check`(가져가는지 시험, 게시 안 함) → `--publish`(확인 질문 후 게시).
- 이 스타터는 **바로 게시만**. 예약 게시는 다루지 않는다.
- 짧은 시간에 여러 번 올리면 스팸 의심(2207051) → 간격 두기.
