# 3. 내 인스타툰 하네스 만들고 첫 편

이 저장소에는 완성된 스킬이 없어요. **재료(`samples/`)만 있고, 내 하네스는 클로드와 같이 만들어요.**

## ① 하네스 만들기
클로드 창에:
> 인스타툰 하네스 구성해 줘. samples 폴더 재료를 써서. 내 툰은 (어떤 툰인지 한두 줄)

(「하네스」라는 말이 들어가면 harness 가 알아서 켜져요. 안 켜지면 `/harness:harness` 를 쳐서 직접 부르세요.)

클로드가 물어보는 것에 답하면 돼요. 보통 이런 걸 물어요.
- 어떤 툰인가요? (일상툰·정보툰·옛날이야기 각색 …)
- 그림은 ChatGPT 에 붙여 넣을 프롬프트로(기본)? API 로 자동으로(유료)?
- 어디서 멈춰서 확인받을까요? (대본·그림 비용·카드·캡션·업로드)
- 릴스까지 할까요? 마지막은 「올릴 꾸러미」까지만?

끝나면 `.claude/agents/` 와 `.claude/skills/` 에 **나만의 에이전트·스킬**이 생겨요. 클로드를 한 번 껐다 켜면 켜져요.
완성된 견본이 궁금하면 `samples/참고_스킬/` 을 열어 보세요.

## ② 첫 편
> 인스타툰 새 편 만들자. 이야기는 이거야: (내 이야기)

방금 만든 하네스가 순서대로 진행해요. 결과는 `episodes/EP01_제목/` 에 쌓여요.

1. **이야기** — 상황 → 「그런데」 꺾이는 지점 → 그날 남은 마음
2. **대본** — 컷마다 그림과 글자를 표로. 그림 뽑기 전에 여기서 확정
3. **그림** — 기본은 **ChatGPT 복붙**이에요(API 키 없이, 구독 중인 ChatGPT 웹에서).
   - 클로드가 컷마다 프롬프트를 만들어 줘요 → 「s1 복사해 줘」 → ChatGPT 에 **캐릭터 그림 첨부 + 붙여 넣기** → 나온 그림 다운로드
   - 컷마다 반복 → 다 받으면 「받은 그림 가져와 줘」 → 받은 순서대로 컷 이름을 붙여 줘요(짝을 먼저 보여 줌)
   - 주인공을 새로 만들 땐 캐릭터 시트(`character`)부터 한 장
   - (유료 자동) 컷이 많아지면 OpenAI API 로 자동으로 뽑을 수도 있어요 → 터미널 새 탭에서 `bash tools/set_key.sh OPENAI_API_KEY`, 뽑기 전에 「몇 장 × 얼마」를 먼저 보여 줘요
4. **카드** — 그림 위에 말풍선·나레이션·효과음 → `card1.png …`
5. **릴스** — 「릴스로 만들어 줘」
6. **캡션**
7. **올릴 꾸러미** — 「올릴 꾸러미 만들어 줘」 → `올리기/` 폴더(01.jpg… · reel.mp4 · 캡션.txt) → 에어드롭 → 인스타 앱에서 01부터 순서대로
   - 보너스: 「크롬으로 instagram.com 에 올려 줘, 공유 버튼 직전에 멈춰」(`claude --chrome`, `samples/노하우/06` ②)
   - 선택: API 연결(docs/02)을 해 두면 「올려 줘」로 바로 게시

## 남의 이야기로 만들 때 (전래동화·탈무드·책 내용 등)
- 아주 오래된 이야기(원전)는 누구나 쓸 수 있지만, **요즘 나온 번역서·그림책 문장은 그 책의 저작권**이에요.
- 그래서 **줄거리만 가져오고 문장은 새로 써요.** 「줄거리만 참고해서 우리 말로 새로 써 줘」.
- 남의 캐릭터(만화·게임·브랜드 캐릭터)는 그리지 않아요.
- 글꼴·효과음·AI 그림까지 올리기 전에 확인할 것은 `samples/노하우/07_저작권_라이선스_체크.md` 에 신호등(🟢🟡🔴)으로 정리해 뒀어요. 하네스를 만들 때 「업로드 전에 라이선스 체크 단계 넣어 줘」라고 하면 자동으로 확인해요.
