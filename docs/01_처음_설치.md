# 1. 처음 설치 (맥, 한 번만)

아무것도 없는 맥에서 시작해요. 순서대로 따라 하시면 되고, 막히면 화면에 나온 글자를 그대로 클로드에게 보여 주시면 돼요.

## ① 터미널 열기
`command + space` → 「터미널」 입력 → 엔터. 검은(또는 흰) 창이 뜨면 여기에 명령을 붙여 넣어요.

## ② Homebrew 설치 (맥 프로그램 설치 도구)
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
- 맥 로그인 비밀번호를 물어보면 입력해요(입력해도 화면에 안 보이는 게 정상이에요).
- 끝에 「Next steps」로 나오는 두 줄(`echo ... >> ~/.zprofile`, `eval ...`)도 복사해서 실행해요.
- 이때 개발자 도구(git 등)도 함께 설치돼요. 몇 분 걸려요.

## ③ Claude Code 설치
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
설치가 끝나면 터미널을 껐다 켜고 `claude` 를 입력해요. 처음엔 브라우저가 열리면서 로그인을 해요(유료 구독 계정).

## ④ 이 저장소 받기
```bash
cd ~/Desktop
git clone https://github.com/<저장소 주소>.git instatoon
cd instatoon
claude
```

## ⑤ 클로드에게 세팅 맡기기
클로드 창에 이렇게 써 보세요.
> 이 폴더 세팅해 줘

클로드가 `setup.sh` 를 실행해서 나머지 프로그램(node·ffmpeg 등)을 설치하고 예시편으로 시험까지 해요.
「이 명령을 실행해도 될까요?」라고 물으면 내용을 보고 허락하시면 돼요.

## ⑥ harness 플러그인 켜기
이 폴더를 처음 열면 「harness 플러그인을 설치할까요?」라고 물어요 → 설치. 안 물어보면 클로드 창에:
```
/plugin marketplace add revfactory/harness
/plugin install harness@harness-marketplace
```
설치 후 클로드를 한 번 껐다 켜요(`/exit` → `claude`). harness 는 「하네스 만들어 줘」 한마디로 에이전트·스킬을 설계해 주는 플러그인이에요.

## 이 폴더에 들어 있는 편의 세팅
| 세팅 | 하는 일 |
|---|---|
| 파일 편집 자동 허용 | 클로드가 파일을 고칠 때마다 허락 버튼을 누르지 않아도 돼요 (`shift+tab` 으로 모드 전환) |
| 끝나면 「띵」 | 작업이 끝나면 소리가 나요. 다른 일을 하다 와도 돼요 |
| 상태줄 | 대화가 얼마나 찼는지 아래에 표시돼요. 🔴가 되면 `/clear` 로 새로 시작하세요 |
| 비밀 차단 | 클로드가 `.env`(키·토큰 파일)를 열어 보거나 깃허브에 마음대로 올리지 못하게 막혀 있어요 |
| harness 플러그인 | 이 폴더에 등록돼 있어서 처음 열 때 설치를 물어봐요 |

설정 파일: `.claude/settings.json` — 바꾸고 싶으면 클로드에게 「알림 소리 꺼 줘」처럼 말하면 돼요.

## (선택) 클로드가 브라우저·화면을 직접 다루게 하기
- **크롬 조작**: 크롬 웹스토어에서 「Claude」 확장을 설치하고 같은 계정으로 로그인해요. 그러면 「이 사이트 열어서 ○○ 해 줘」가 돼요.
- **화면 조작**: 맥 「시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 / 화면 기록」에서 허용해야 해요.
툰 만들기에는 둘 다 없어도 돼요.
