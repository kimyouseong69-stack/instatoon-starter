# 2. (선택) 인스타 API 바로 게시 연결 (Meta API)

> **처음엔 안 해도 돼요.** 기본은 「올릴 꾸러미 만들어 줘」 → 휴대폰 앱에서 직접 올리기예요(음악도 붙일 수 있어요).
> 매일 올리게 되고 「올려 줘」 한마디로 끝내고 싶을 때, 나중에 예약·자동화까지 가고 싶을 때 해 보세요. 업로드 세 가지 방법은 `samples/노하우/06_업로드.md`.

처음 하는 분께 가장 어려운 단계예요. 한 번만 해 두면 그다음부터는 「올려 줘」 한마디로 돼요.

## 필요한 것
| | 필요? |
|---|---|
| 인스타 계정 (프로페셔널: 크리에이터 또는 비즈니스) | 필요 |
| 페이스북 **개인** 계정 | 필요 (Meta 개발자 등록이 페이스북 로그인으로만 돼요) |
| 페이스북 **페이지** | 필요 없음 |
| 앱 검수·사업자 서류 | 필요 없음 (내 계정에만 쓰는 앱이면) |
| 카드 결제 | 필요 없음 |

## ① 인스타 계정을 프로페셔널로
인스타 앱 → 프로필 → 메뉴(≡) → 설정 및 활동 → 「계정 유형 및 도구」 → **프로페셔널 계정으로 전환** → 카테고리 → 크리에이터 또는 비즈니스.
페이스북 페이지 연결은 **건너뛰기**. 계정은 **공개**여야 해요.
- 새로 만든 계정이면 생일·전화 인증 같은 확인을 요구할 수 있어요. 끝까지 해 두세요(안 하면 업로드 때 「계정 제한」 오류).

## ② Meta 개발자 등록
페이스북에 로그인한 상태로 https://developers.facebook.com → **Get Started** → 약관 동의 → **전화번호·이메일 인증 코드** 입력 → 직업 선택.
- 새로 만든 페이스북 계정은 「평소와 다른 기기」라며 막힐 때가 있어요. 그럴 땐 휴대폰 페이스북 앱에서 로그인 확인을 하고 잠시 뒤 다시 해 보세요.

## ③ 앱 만들기
오른쪽 위 **Create App** → 앱 이름(아무거나, 예: `my-toon`) → 사용 사례에서 **「Instagram에서 메시지 및 콘텐츠 관리 (Manage messaging & content on Instagram)」**
(화면에 그 항목이 없으면 **Other → Business**) → 비즈니스 포트폴리오는 「아직 연결 안 함」 → 끝까지 Next → 대시보드로.

## ④ 인스타 계정 연결하고 토큰 받기
대시보드 왼쪽 **Instagram → API setup with Instagram login** → 「Generate access tokens」에서 **Add account** → 인스타 로그인·허용 → 계정 옆 **Generate token** → 복사.
- 계정이 「Pending(대기)」로 남으면: 인스타 웹 → 설정 → 앱 및 웹사이트 → 테스터 초대 → 수락.
- 이 토큰은 **60일** 쓸 수 있어요. 만료되면 같은 버튼으로 다시 받아요.

## ⑤ 토큰을 .env 에 넣기 (★여기가 제일 중요)
토큰은 **비밀번호와 같아요.** 클로드 대화창·카톡·스크린샷에 절대 붙이지 마세요.
터미널 **새 탭**(`command + T`)을 열고:
```bash
cd ~/Desktop/instatoon-live
bash tools/set_key.sh IG_ACCESS_TOKEN
```
붙여 넣고 엔터 — 글자가 화면에 안 보이는 게 정상이에요(발표·녹화 중에도 안전). 끝 4자리만 보여 줘요.
(클로드는 `.env` 를 못 열게 막혀 있어요.)

## ⑥ 연결 확인
클로드에게: 「인스타 연결됐는지 확인해 줘」 → `samples/엔진/upload/ig_publish.py whoami` 가 **@내계정** 을 보여 주면 성공이에요.

## 올리기
클로드에게: 「EP01 캐러셀 올려 줘」 / 「EP01 릴스 올려 줘」
1. 먼저 `--check` 로 인스타가 파일을 가져가는지 시험해요(게시 안 함).
2. 그다음 `--publish` → 「@계정 에 올립니다, 계속?」에 `y`.

알아 두면 좋은 것:
- 인스타는 내 컴퓨터 파일을 직접 못 받아서, 스크립트가 **잠깐 쓰는 공개 주소**를 만들어 넘겨줘요(cloudflared 임시 터널, 끝나면 사라짐).
- 캐러셀은 API로 **2~10장**까지예요(앱은 20장). 이미지는 자동으로 JPEG 로 바꿔서 보내요.
- API로 올린 릴스에는 음악을 붙일 수 없어요. 음악이 필요하면 앱으로 올려요.
- 예약 게시는 이 스타터에 없어요(바로 게시만).
